# Concepts

These pages explain how Skye is built and why, so the guides and the reference make sense together.

- [Architecture](architecture.md): the four layers, the fifteen components, the Ports in `base` and the import rules that keep
  them apart.
- [Serverless first](serverless-first.md): why the standard library, how the size and cold-start budgets are enforced, and what
  that means for your Lambda function.
- [The .skye language](skye-language.md): one small language for routers and prompts (and, later, flows), with a checker, a
  formatter and a diagram renderer.
- [Agents (preview)](agents-preview.md): the agent loop as designed. Not released yet.

The words used across the site (Port, component, capability, extra, codename) are defined in the [glossary](../project/glossary.md).
