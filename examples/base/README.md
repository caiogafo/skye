# base

What you learn: the base types. Read in this order:

1. `content_chunks.py`: Base content types: ContentChunk and StreamChunk (Live)
2. `errors.py`: The SkyeError hierarchy (Live)

Run: `python examples/base/content_chunks.py`

What you see: printed results; with no key a scripted client answers and the example prints which mode ran.

What you need: `pip install skyeai`; a provider key only to call a real service.
