# memory

What you learn: memory. Read in this order:

1. `conversation_memory.py`: Conversation memory over the memory Port (proposed-interface, guarded)
2. `custom_memory.py`: Custom memory store: the extension point of the memory Port (proposed-interface, guarded)

Run: `python examples/memory/conversation_memory.py`

What you see: printed results; with no key a scripted client answers and the example prints which mode ran.

What you need: `pip install skyeai`; a provider key only to call a real service.
