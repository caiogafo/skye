# Skye example coverage: 26 interface-validation scripts, ruff gate now clean

This task adds 26 standalone example scripts plus the `examples/README.md` category index so the owner can read Skye's public surface end to end before a dedicated spec exists. The scripts cover `base`, `models`, `auth`, `store`, `tools`, `memory`, `guard`, `policy`, `observe`, `gateway`, `agents`, `teams` and `flows`. Each runs offline under `tests/examples` against the fake network with no optional/provider libraries installed. Where the public API already ships in `src` the example is "Live"; where it does not (memory stores, the gateway serve entry point, teams/flows orchestration, the ReAct loop) it is "proposed-interface, guarded": it builds the intended shape from real Ports and dataclasses, then returns before touching anything unimplemented.

The prior pass (`2026-11-03-223913-review.md`) flagged one blocking issue: `examples/agents/agent_with_hooks.py` failed ruff `I001` because an uncommitted facade rewrite had split the Port imports into four consecutive `from skye.interfaces import ...` lines. Commit `7a62411` merged them into one sorted block, and `uv run ruff check` on the new paths is now clean (confirmed). No new concerns surfaced on this pass.

Watch for: nothing blocking. The working tree still carries a separate, uncommitted import-facade / pydantic-removal workstream that edits out-of-scope `src/` and example files, but it is not this task's work and the task's committed range leaves every out-of-scope file untouched (confirmed).
