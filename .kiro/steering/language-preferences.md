# Preferenze di lingua (italiano)

Regole concordate con l'owner per le risposte e i documenti in italiano.

## 1. Prestiti dall'inglese: invariabili al plurale
In italiano i termini presi dall'inglese NON prendono la "-s" del plurale.
Il numero si esprime con l'articolo/contesto, la parola resta invariata.

- il task / i task        (NON "i tasks")
- il file / i file        (NON "i files")
- il token / i token
- il provider / i provider
- il model / i model
- il flow / i flow
- il tool / i tool

## 2. Genere di "task": maschile
Si dice "il task" / "i task" (maschile), non "la task".

## Nota
Queste regole valgono per tutta la prosa in italiano (risposte in chat e,
quando scritti in italiano, i documenti). I nomi tecnici in codice, i path e
gli identificatori restano invariati come da lingua originale.
