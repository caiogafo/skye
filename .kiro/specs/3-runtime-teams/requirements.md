# Requirements Document

## Introduction

Coordination of several units toward a shared objective. This spec is at the requirements stage: the design and the tasks come after the requirements are approved.

The requirements themselves live in `.kiro/steering/10-requirements.md`; each requirement below is one user story of this component, and each acceptance criterion is a pointer to the steering criterion it realizes (never a copy).

## Requirements

### Requirement 1: Teams

**User Story:** As a developer, I want to coordinate several units (models, agents, flows or other teams) toward a shared objective, so that I can build multi-unit behavior from one abstraction.
