## Introduction

Conversation and state memory behind one Port. This spec is at the requirements stage: the design and the tasks come after the requirements are approved.

The requirements themselves live in `.kiro/steering/10-requirements.md`; each requirement below is one user story of this component, and each acceptance criterion is a pointer to the steering criterion it realizes (never a copy).

## Requirements

### Requirement 1: Memory

**User Story:** As a developer, I want conversation and state memory behind one Port, so that agents can remember without depending on a particular store.
